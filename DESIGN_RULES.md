# Interface Design Rules

Use these rules for every new screen and component.

1. Use one centered content column with a maximum width of 560px.
2. Use only the shared small, label, body, and title text sizes.
3. Use no more than regular, semibold, and bold font weights on one screen.
4. Keep form controls and primary actions at least 50px high.
5. Align related cards to the same width and use equal gaps and padding.
6. Keep labels short, sentence case, and left-aligned. Reserve uppercase for small status labels.
7. Use one primary action per screen. Secondary actions must be visually quieter.
8. On mobile, stack controls in one column and keep buttons full-width.
9. Prefer whitespace and hierarchy over extra borders, colors, or decorative text.
10. Check desktop and 320px mobile layouts before publishing.
