# Child Usability Review

Date: 2026-11-01

Scope: heuristic review of the current desktop and responsive layouts. This does not replace observing a child complete a full round.

## What already works

- The screen has one clear task and no advertising or distracting navigation.
- The vertical equation matches familiar worksheet notation.
- Answer choices are large, evenly spaced, and keyboard accessible.
- Progress, remaining questions, and time are easy to locate.
- Accuracy is emphasized before speed.
- Results explain mistakes only after the round, as intended.

## Changes recommended before publication

### 1. Prevent accidental double answers — completed

A question-identity guard and input lock now prevent rapid or queued clicks from skipping a question. Answer buttons are disabled immediately after the first accepted selection.

### 2. Clarify review wording — completed

The interface now uses the shorter labels “Repeats,” “Repeats next round,” and “Practice these again.”

### 3. Add a calm timer option — later

The timer supports the product goal, but a constantly visible countdown may increase anxiety for some children. A later parent setting could hide the countdown while still recording elapsed time.

## Parent observation checklist

Ask the child to complete one round without coaching. Observe whether they:

- Understand how to begin without explanation.
- Recognize the vertical multiplication format.
- Know that they must select one of three answers.
- Understand that results will appear at the end.
- Can read all text and tap each choice comfortably.
- Remain comfortable with the countdown.
- Understand the corrections and how to start another round.

Record where they pause, ask a question, mis-tap, or lose interest. Adjust only from observed friction rather than adding features preemptively.
